# 360 homepage implementation plan

**Goal:** Build a responsive coming-soon homepage for 360 using the supplied circle-grid clothing concepts. The user selected a brand launch, not a shop.

**Architecture:** A small React application with native CSS. Product data, circle artwork, collection browsing, and garment details have separate modules. Native dialog provides keyboard focus containment. No checkout, invented stock, prices, or mailing-list submissions.

**Tech stack:** React, TypeScript, Vite, self-hosted Space Grotesk and Space Mono.

**Spec:** `DESIGN.md` and the user's garment and mall-sign references.

- [x] Scaffold Vite, React, TypeScript and scripts for development and production builds.
- [x] Create a ring-matrix 360 wordmark and a dark editorial hero with a campaign photograph.
- [x] Add four design previews with black/white swatches and accessible garment detail dialogs. No shop filters, prices, sizes, or purchasing controls.

- [x] Update DESIGN.md with the implemented palette, typography, responsive rules, and prototype scope.

## Design decisions

Use the existing monochrome direction, square corners, and fine borders. Tighten display tracking while retaining spaced small labels. Product photos use CSS viewports of the supplied contact sheet. Browser controls describe concepts rather than pretending garments are for sale. Preserve the original design document and record implementation-specific changes in an addendum.
